Plano de projeto

Locutor Camisa Treze

Sistema de locução automática para a casa lotérica em Brasília: texto de propaganda escrito por IA, sempre revisado por humano, narrado pela Amazon Polly e tocado numa caixa de som Bluetooth dentro da loja.

Loja: Loteria Camisa Treze — Brasília Hardware da loja: PC Windows, 8 GB RAM Distribuição: GitHub Pages (grátis)

Visão geral

A ideia nasceu de uma propaganda que seu pai recebeu: um produto pronto para casas lotéricas que toca, numa caixa Bluetooth, áudios gerados por IA anunciando os próximos sorteios e bolões. Em vez de assinar esse produto, a proposta aqui é construir uma versão própria — mais barata e sob controle da família.

O princípio central é o mesmo que seu pai pediu: nenhum áudio vai ao ar sem passar por revisão humana. A IA só rascunha o texto a partir de dados reais — sorteio, valor da cota, prêmio, prazo do bolão — digitados por quem conhece o negócio.

Arquitetura

Todo o trabalho de IA e de conversão de texto em voz roda de graça no GitHub Actions, e o próprio GitHub Pages publica os áudios prontos. A loja só baixa o resultado e toca — e como tudo vive na nuvem, a planilha pode ser atualizada de qualquer lugar, não só do notebook da lotérica.

Fluxo passo a passo

  1. Alguém digita os dados do sorteio ou bolão na planilha — loteria, data, valor, prêmio, prazo.

  2. Uma rotina agendada no GitHub Actions lê as linhas novas e pede à IA um rascunho de locução.

  3. O rascunho volta para a planilha para revisão. Alguém edita se precisar e muda o status.

    Pendente Aprovado Publicado

  4. Uma segunda rotina detecta as linhas aprovadas e envia o texto à Amazon Polly, que devolve o áudio.

  5. O áudio e a lista atualizada de conteúdos ativos são publicados no GitHub Pages.

  6. O computador da loja verifica essa lista periodicamente, baixa o que é novo, apaga o que venceu e toca os áudios na caixa Bluetooth durante o funcionamento da loja.

Decisões em aberto

Qual serviço vai gerar o texto?

Sugestão: API da Anthropic (Claude Haiku) — custo baixíssimo para textos curtos, mas exige criar uma chave de API própria.

Qual voz da Polly usar?

Sugestão: testar as vozes neurais em português do Brasil e deixar seu pai escolher pelo ouvido.

Em que horário e com que frequência os áudios devem tocar?

Depende do fluxo de clientes na loja — defina uma janela (ex.: 8h–18h) e um intervalo mínimo entre áudios.

Quem mantém a conta AWS e a chave de API?

Provavelmente você — envolve cartão de crédito e faturas que seu pai não deve precisar gerenciar.

E se a internet da loja cair?

Sugestão: o player sempre toca a partir da pasta local; internet só é necessária para buscar áudios novos.
